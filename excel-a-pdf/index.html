Excel a PDF: convertí tu planilla en un documento

Subí tu planilla y descargá el PDF. Elegí si querés que respete la configuración de impresión o que cada hoja entre en una sola página.

Cómo armar el PDF

El archivo se envía a nuestro servidor solo para convertirlo y se elimina apenas termina. No se guarda ni se usa para otra cosa.

Cómo funciona

Subís tu planilla y el servidor la abre con un motor de oficina (LibreOffice) y la exporta a PDF. Tenés dos modos:

  • Como se imprime: el PDF sigue la configuración de página del archivo (área de impresión, orientación, tamaño de papel, márgenes y saltos de página), igual que cuando imprimís. Es lo más parecido a «Guardar como PDF» de Excel.
  • Una página por hoja: cada hoja se exporta completa en una única página, sin cortes entre columnas ni filas. Sirve para planillas anchas, aunque las páginas resultantes pueden ser muy grandes.

Formatos admitidos

Excel (.xlsx y .xls), OpenDocument (.ods) y CSV, hasta 25 MB. Se convierten todas las hojas del libro.

Para que salga bien

  • Si una planilla se corta en varias páginas, definí el área de impresión y la orientación en Excel antes de convertir, o usá el modo «Una página por hoja».
  • Las macros no se ejecutan y los vínculos externos no se actualizan: se usan los valores guardados en el archivo.
  • Los libros protegidos con contraseña no se pueden convertir.

Tu archivo se envía a nuestro servidor solo para convertirlo y se elimina apenas termina. No se guarda ni se usa para otra cosa.

Ejemplo

Una planilla de gastos de 2 hojas, con una tabla de 21 columnas, se corta en varias páginas al imprimirla. En modo «Como se imprime» obtenés el PDF paginado como lo haría Excel con su configuración. En modo «Una página por hoja» obtenés un PDF de 2 páginas, una por hoja, con toda la tabla visible de una vez.

Preguntas frecuentes

¿Se guarda mi planilla?

No. Se envía a nuestro servidor únicamente para convertirla, se procesa en un espacio temporal y se elimina apenas termina.

¿Qué diferencia hay entre los dos modos?

«Como se imprime» respeta la configuración de página del archivo y puede dividir una hoja grande en varias páginas. «Una página por hoja» exporta cada hoja entera en una única página, que puede quedar muy grande si la hoja es extensa.

¿Se convierten todas las hojas del libro?

Sí, el PDF incluye las hojas del libro, una a continuación de la otra.

¿Se calculan las fórmulas?

Se muestran los valores que tiene la planilla al abrirse. Las macros no se ejecutan y los vínculos a otros archivos no se actualizan.

¿Hay límite de tamaño?

Sí, 25 MB por archivo, y se limita la cantidad de conversiones seguidas desde una misma conexión.

¿Puedo convertir un archivo CSV?

Sí. Se abre como una planilla de una hoja y se exporta a PDF.
